# Constitution

この文書は、実装方法より上位にある「この作品が何のために存在し、何を守るか」を記録します。

## 作品の目的

- `PROJECT_BRIEF.md` を基に、ユーザーと確認した目的を記載する。

## 守る価値

- 未確定。企画・仕様検討で合意した内容だけを追加する。

## 変えてはいけない原則

- ユーザーの明示的な合意なしに、作品の目的・対象ユーザー・中核体験を変更しない。
- 技術都合だけを理由に、作品の中核価値を別物へ置き換えない。

## 変更ルール

この文書を変更する場合は、単なる実装変更ではなく作品思想の変更として扱い、理由を `docs/DECISIONS.md` に残す。
