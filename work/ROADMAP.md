# Roadmap

この文書は制作工程を管理します。Control の lifecycle (`WORKING` / `PUBLIC` など) とは別概念です。

## Goal

`PROJECT_BRIEF.md` の目的と確定仕様を満たす完成作品を作る。

## Phases

1. **企画・仕様整理** — Constitution、Requirements、Unresolved を整理する。
2. **初期実装** — 中核体験が動く最小構成を作る。
3. **機能完成** — 合意済みRequirementsを満たす。
4. **検品・修正** — Acceptanceに基づいて確認する。
5. **公開準備** — ユーザーが公開を希望した場合のみControlの公開フローへ進む。

## Current phase

新作作成時点では `PROJECT_BRIEF.md` 確認後に設定する。

## 変更ルール

ロードマップ変更で作品の目的や確定仕様を暗黙に変更しない。仕様変更が必要なら先にユーザー確認とRequirements/Decisions更新を行う。
