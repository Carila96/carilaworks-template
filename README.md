# CARILA WORKS Project Template

CARILA WORKS で新しい作品を作るための GitHub Template Repository です。

## 新作を始めるとき

1. GitHub の **Use this template** から新しいリポジトリを作成します。
2. `README.md` を作品の概要と利用方法に書き換えます。
3. `carila-project.json` の仮値を、作品固有の情報へ置き換えます。
4. `AGENTS.md` の共通制作ルールを確認してから制作を開始します。

公開、デプロイ、DNS・サブドメインの変更など、外部状態を変える操作は、ユーザーの明示的な承認を得てから実施してください。
